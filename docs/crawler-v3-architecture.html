适配与组装层

Adapter 接外部接口；Factory 根据配置创建实现；DI 传依赖；Repository 管窄数据访问；Strategy 只用于真正变化的规则。

编排与运行层

Workflow 组织依赖；runner 管 Activity / Worker；bootstrap 管依赖生命周期；deploy 管平台启动，不把主机细节带进核心。

容器的边界

  • 每 Worker 进程一个根容器，显式注册，不自动扫目录。
  • 并发安全客户端可复用；产品 / 页签状态按操作或隔离 Lane 管理。
  • singleton 不是跨机器单例；任务 scope 不是持久 Workflow 内存。
  • 显式注册并调用释放逻辑，不能指望容器自动关掉所有资源。

统一质量规则

  • 外部输入运行时校验，不用 any 掩盖不完整数据。
  • 不可变结果与证据追加保存，不共享可变产品对象。
  • 无隐藏重试、模型修复、自动换 Provider 或清理。
  • 类型 / 静态 / 格式检查 + 正常、缺失、冲突、故障测试；单测不调生产。
